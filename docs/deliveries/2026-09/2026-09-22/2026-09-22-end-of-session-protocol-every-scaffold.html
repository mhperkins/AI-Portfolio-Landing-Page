The four steps

01

Current State

Rewrite the project's snapshot. Prune finished items, add new ones. Overwrite, do not append.

02

Changelog

What changed, why, the effort level and the date. Newest at the top. A conversation session still gets an entry.

03

Commit and push

PowerShell for all git. Stage by name, never -A. Message ends in the Co-Authored-By line.

Most forgotten
04

Delivery slide

One self-contained HTML slide with cards, badges, the commit hash and the branch, in the project's palette.

Most forgotten
Why it kept getting missed. This repo's CLAUDE.md carried a two-step version: update Current State, then commit and push. Not wrong, just short by half, and a session reading it had no reason to think anything was missing. That text is now a pointer to the full four.

Judgment calls

Not a rewrite

Composer's Compass kept its own

  • Its protocol is richer than the generic one: track routing for UI against training, two changelogs, session numbering per track.
  • It got the four-step framing header and a mapping table on top. Nothing was replaced.
  • Two deviations preserved and marked as winning here: the slide ships inside the final commit, and it carries no hash, because the hash cannot exist before its own commit.
  • It is also the one repo on master.
Redundant on purpose

Global, and a full copy in each

  • The canonical text is in ~/.claude/CLAUDE.md, so a scaffold created next month inherits it without anyone remembering.
  • Each project still carries the full text, so none of them depends on the global file being loaded.
  • Where the two differ, the project wins, because the six local values are its own.
Found on the way

Three things worth fixing

  • Stale attribution: sprout-crm-next still asked for Claude Opus 4.8. Now Opus 5.
  • Two Sprout CLAUDE.md files are gitignored, so their Current State lives on disk only and never appears in a commit. Written into their copies so no session assumes otherwise.
  • virtual-agency is not a git repo, so step 3 has nothing to commit. Its copy says to do the other three and say so.
Open: three projects have no CHANGELOG.md yet. Grant Tool v2 and sprout-social-tool are told to create one on the first session that runs the protocol; virtual-agency leans on its Current State until it has one. And the teaching-page worktree still holds the branch's own copy of the portfolio CLAUDE.md, which will take main's version when it merges.
