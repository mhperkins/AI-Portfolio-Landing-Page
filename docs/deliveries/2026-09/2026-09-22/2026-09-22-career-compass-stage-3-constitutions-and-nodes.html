What shipped into ai.py

01

The constitution arrives

store.track_of() reads a Track: line in job.md, falling back to the template. Every folder was given one; new applications get one automatically. A track with no file contributes nothing, silently.

02

One node per turn

The single ROLE became CORE plus one NODES entry: partner, review, draft, advise. Chips name a node; free text gets partner, so nothing regresses.

03

The node goes in messages

Never in the top-level system, which would rewrite the cached prefix on every switch. One cached system prefix serves all four nodes.

04

Enforced in code

Each node's output surface is stripped in node_output(), not trusted to the prompt. A turn asked only for marks cannot return a draft that overwrites the document.

"Paid to find where models fail" is phrasing Max struck himself, and the stage 1 runs reproduced it twice. Absent is the problem, not the fix: a one-sheet that never mentions it leaves the Draft node free to write it. Every constitution run puts it under Cut and never claim instead, including both held out applications, where no rule came from the folder being scored.

What it cost, reported rather than buried

Source labels fell 22%, 16.5 to 12.9 per run, at unchanged length. Constitution references went from 0 to 34 over the same runs, and total attribution stayed roughly flat, which is what displacement looks like: the constitution cites a decision behind every rule, so it reads like a sourced document and the agent attributes to it instead of tracing the fact. Acted on, not logged: CORE now says a fact traces to profile.md, notes.md or the posting, and that a constitution is not a source for one.
One stage 2 output was destroyed. A patch applied its signature and not its body, so a --constitution run added no constitution and wrote to the plain output name. It reached Clasp before it was caught. Same arm and same inputs, so it is a second sample rather than a lost measurement. run_strategy.py now archives an existing output before writing, and a silent string-replace patch is no longer how that file gets edited.

Honest limits

Contamination

Six of eight teach to the test

  • Both constitutions were extracted from the six catalog applications and cite those folders by name, so those runs measure uptake, never prediction.
  • Every transfer claim rests on Brady Martz and Estrada alone, n=2.
  • Neither held-out folder has a notes.md, so their benchmark is the documents Max sent rather than a written rationale.
Scale

Comparison documents, not metrics

  • Eight applications. Nothing here is a rate or a score, and the app displays none.
  • One gate could not discriminate at all: v0.2's scope rule had already fixed the $1.5 million handling, so the constitution had nothing to add. Same shape as stage 2's invention gate.
  • A first source count read one run at zero because it wrapped filenames in backticks. Read what the runs write before trusting a count.
