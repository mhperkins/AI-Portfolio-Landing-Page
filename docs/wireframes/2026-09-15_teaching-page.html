    Open calls

    each has a recommendation; answer by number
    1. 1
      The Activity card's name

      These are topics, not classes. "Activity" and "Exit ticket" read as classroom terms.

      Recommend: Objective · Try it · Check yourself.

    2. 2
      The 15-week map

      It shows this is the opening of a full course without writing a syllabus. Week names come from the curriculum draft.

      Recommend: keep it.

    3. 3
      The practice rail

      Seven practices: Memory, Version control, Effort, Wireframe, Verify, Evaluate, Guardrails. Building with AI introduces each one; the two build stories light the one each slide shows. Every practice lights at least once.

      Recommend: yes, on both topics.

    4. 4
      A source line on build slides

      A file and date under each build-story slide, so the committee sees these happened.

      Recommend: keep it, small and grey.

    5. 5
      TeacherAID privacy

      The repo carries the teacher's real name, UW employers, course codes, student names and pay. A UW committee could identify the teacher from any of it.

      Recommend: placeholder data in every visual, no exceptions.

    6. 6
      New second activity

      "Score two suggestions" no longer fits a build story. "Name the practice" ties the two halves of the final-round session together.

      Recommend: use it.
