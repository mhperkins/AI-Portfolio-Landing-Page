## CREATIVE WORK & RESEARCH: THE COMPOSER HUB

Most AI music tools today serve non-musicians: type a prompt, get a finished track, no training required. This work does the opposite: AI tools built for musicians, not to write the music for them, but to sharpen their creative process, develop their careers, and work more efficiently. The Composer Hub is three tools: The Composer Compass, Composer CRM, and Virtual Agency, each aimed at a different part of what a working composer actually has to do.

### The Composer Compass (2026-present)
*An AI composer assistant that does not compose music; it learns your compositional process and augments your creative capacity through a structured protocol in the background and a simple interface in the foreground.*

- Learns a composer's process from a structured intake form filled out per piece, then evaluates new work against it: trained via an AI analysis agent and a rubric scoring six compositional dimensions plus three modifiers.
- Grounds every evaluation in the composer's own reference material, not generic AI assumptions, via a searchable personal music theory library (ChromaDB, sentence-transformer embeddings).
- Guides the composer through the actual creative workflow in a Next.js interface built on the Anthropic API: planning, rough draft, detailed draft, and engraving.
- Tested the trained agent across several AI models to compare how reliably each one captures and reinforces an individual compositional process, rather than defaulting to its own.

### Composer CRM (2026-present)
A working tool for running a composing and performing practice, live and used daily: the career-development piece, since a composer's career is also a small business that needs one place to run from instead of scattered email and spreadsheets.

- Tracks contacts, organizations, and concerts (budgets, communications, media), plus newsletters, outreach, and prospects.
- Includes one AI feature already: a newsletter-polishing step, extended further in Virtual Agency.

### Virtual Agency (2026-present, in training)
A set of AI agents that run the supporting work of the same practice, marketing, web design, social media, relationship management: the efficient-workflow piece, testing AI on the actual work of running a music career rather than composition itself.

- Each agent is a job description (a system prompt) plus a set of tools, run from the command line, on a schedule, or as a sub-task.
- Built three so far, Marketing, Web Design, and Social Media, each shipping real work: a concert landing page, an 11-person outreach campaign, a two-week content calendar.
